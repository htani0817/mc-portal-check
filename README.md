# mc-portal-check

ネザーゲートを建てる前に、近くの既存ゲートと**干渉しないか**を調べて画面の右上に出す、NeoForge 26.2 の Mod です。「建てたら別のゲートにつながってしまった」「戻ったら元のゲートに出ない」を、建てる前に分かるようにします。

- 対象: Minecraft 26.2 / NeoForge 26.2.0.88 以降
- 入れる場所: **サーバーと、各プレイヤーのクライアントの両方**（反対側の次元のゲートはクライアントから見えないので、判定はサーバーで行います）
- Mod を入れていないクライアントもサーバーに入れます（表示が出ないだけです）
- シングルプレイでも動きます

> [!NOTE]
> 1.0.0 はプレリリースです。負荷の高いサーバーで、ゲートに火を付けた直後の表示がすぐ変わるかはまだ確かめていません。

## 導入

1. [Releases](https://github.com/htani0817/mc-portal-check/releases) から `mc-portal-check-<版>+mc26.2-neoforge.jar` をダウンロードします
2. サーバーの `mods/` に置いて、サーバーを再起動します
3. 各プレイヤーのクライアントの `mods/` にも置きます

サーバーとクライアントは、同じ版にそろえてください。

## いつ出るか

| 場面 | 表示 |
| --- | --- |
| 黒曜石・火打石と打ち金・ファイヤーチャージを利き手かオフハンドに持っている間 | 「ここに建てると」: 足元にゲートを建てたときの結果 |
| 上と同じで、足元の近く（±2 ブロック、高さ -1〜+3）に既存のゲートがあるとき | 「目の前のゲート」: そのゲート自身の結果 |
| 上と同じで、目の前のゲートがサーバーに記録されていないとき | 「目の前のゲート（未登録）」: 直し方を出します（下の「記録されていないゲート」） |
| ゲートに火を付けた直後 | 「建てたゲート」: できたゲートの結果を、16 ブロック以内のプレイヤーに 10 秒出します（手に何を持っていても） |
| 上のどれでもないとき・F1 で HUD を隠したとき | 出しません |

表示はリアルタイムに変わります。立ち止まったままでも、近くでゲートができたり壊れたりすれば、持ち替えなくても更新されます。判定するのはオーバーワールドとネザーにいるときだけです。

## 何を「干渉」とするか

vanilla 26.2 のゲートの行き先の決め方に合わせて計算します。

| 規則 | 内容 |
| --- | --- |
| 行き先の目安 | くぐった人の座標 × 倍率（オーバーワールド → ネザーは ÷8、ネザー → オーバーワールドは ×8）。Y はそのまま |
| 既存ゲートを探す範囲 | ネザーへ行くとき ±16、オーバーワールドへ行くとき ±128。X・Z の正方形で、高さは全域 |
| どれを選ぶか | 目安からの直線距離がいちばん近いゲート。同じ距離なら Y が低い方 |
| 見つからないとき | 目安の近くに新しく作られる |

ここから、次の 3 つを出します。

1. **行き先**: 既存のゲートにつながるか、新しく作られるか
2. **戻り**: 行き先からくぐり直したとき、このゲートに戻るか。別のゲートに出るなら「片道」で、**干渉あり**です
3. **行き先の共有**: 同じ次元のほかのゲートで、行き先がこのゲートと同じになるもの。1 つでもあれば**干渉あり**です

vanilla は「ゲートの位置」ではなく「入った位置」で行き先を決めるので、幅の広いゲートは入る場所で行き先が変わることがあります。この Mod は、建てる前は足元、建てた後はゲートの中央の足元から入るものとして計算します。

## 画面

```text
[ゲート] ゲート干渉チェック          [干渉あり]
ここに建てると 100, -60, 2
→ 行き先  ネザー 1, 64, 0  [既存]
← 戻り    ✕ 別のゲート 1, -59, -2（99 ブロック先）
⚠ 行き先が同じゲート 1 基
    1, -59, -2  99 ブロック先
向こうの探索範囲 ±16 ・ 既存 1 基
```

- 左端の線と右上のバッジは、干渉ありなら赤、干渉なしなら緑です
- 座標は、ゲートの内側（紫のブロック）の X・Y・Z それぞれの最小です
- ステータス効果のアイコンや進捗の通知が出ているときは、その下にずれます
- 表示は日本語と英語に対応しています

## 記録されていないゲート

ブロックはゲートなのに、サーバーのゲートの位置の記録に入っていないゲートができることがあります。そのゲートからくぐって出ていくことはできますが、ほかのゲートからの戻り先には選ばれません（サーバー自身が見失っているためです）。

目の前のゲートがこの状態のときは「未登録」と出ます。**枠の黒曜石を 1 つ壊して、火を付け直す**と記録され直します。離れた場所のゲートは、ブロックを直接見られないので検知できません。

### 確認用コマンド

`/portalcheck debug`（OP のみ）で、いま立っている場所の判定の中身をチャットとサーバーのログに出します。

- Mod が覚えているゲートの一覧での判定と、一覧を作り直したときの判定
- 戻りの探索範囲にあるゲートの記録
- サーバー自身のゲート探索が選ぶゲート（実際にくぐったときに使われるもの。チャンクを読み込むことがあります）

## 既知の制約

- サーバーのプラグインがゲートの探索範囲を変えている場合、表示と実際の行き先がずれます
- 古い版から引き継いだワールドで、ゲートの記録が壊れている場所のゲートは見落とすことがあります
- 行き先が新しく作られる場合、実際の位置は目安から少しずれます（vanilla は目安の近くで置ける場所を探すため）。この Mod は目安の座標ちょうどにできたものとして戻りと共有を計算するので、境目に近いと結果がずれることがあります

## ビルド

```bash
./gradlew build      # Windows は gradlew.bat build。単体テスト込み
```

- できた jar は `dist/` にコピーされます。ビルド出力は `~/.gradle/project-builds/mc-portal-check/` に置きます（場所を変えるときは `-PmcBuildRoot=<パス>`）
- 開発用の起動:

  ```bash
  ./gradlew runServer                              # ポートは server.properties で指定
  ./gradlew runClient -PpcJoin=localhost:25566     # 起動したらそのままそのサーバーに入る
  ```
